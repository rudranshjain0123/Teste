# Teste by ORCATE

**See your website through someone else's eyes.**

Teste is a local-first, AI-powered usability testing utility built for developers, vibe coders and creators.

It allows AI agents to explore websites as simulated users, discover usability problems, capture real browser evidence and generate actionable improvement prompts.

## Download

[**Download Teste 1.0 — Public Beta**](https://github.com/rudranshjain0123/Teste/releases/download/v1.0.0-beta/Teste.zip)

## Features

- AI-driven usability testing
- Predefined and customizable user personas
- Real browser automation
- Desktop and mobile testing
- Screenshot capture and interaction replay
- Evidence-backed usability reports
- Actionable AI fix prompts
- Persistent local audit history
- Regression testing
- Portable audit import and export
- Local MCP integration

## Local-First Architecture

Teste runs on your own computer without requiring an ORCATE account or hosted backend.

Audit history, screenshots and reports are stored locally. External AI providers may process browser observations and impose their own usage charges.

## Beta Notice

Teste is currently in public beta. Some functionality may be incomplete or behave differently across operating systems.

AI-simulated users complement real human usability testing rather than replace it.

Please report bugs and suggestions through GitHub Issues.
